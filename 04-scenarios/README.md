# Scenarios

> **All five scenarios are fictional and illustrative.** Company, supplier and role names are invented; numbers are made up to show the method, not measured data. A real, cited case (Kobe Steel) is referenced only where noted, as an analog.

Each scenario follows the same structure: setup, behavioral drivers, hard-data signals, qualitative signals, what AI surfaces, analyst judgment, human handoff, audit angle, controls and response.

| # | Scenario | Stage | Main drivers |
|---|---|---|---|
| [S1](S1-the-supplier-we-always-use.md) | The supplier we always use | SOURCE | Trust, lock-in, confirmation bias |
| [S2](S2-quarter-end-expedite-rush.md) | Quarter-end expedite rush | DELIVER / ENABLE | Deadline pressure, incentives, authority |
| [S3](S3-the-forecast-nobody-challenged.md) | The forecast nobody challenged | PLAN | Anchoring, optimism, groupthink, authority |
| [S4](S4-friday-evening-risk-acceptance.md) | Friday-evening risk acceptance | MAKE | Deadline pressure, authority, normalization |
| [S5](S5-returns-that-got-softer.md) | Returns that got softer | RETURN | Sunk cost, confirmation bias, softened escalation |
